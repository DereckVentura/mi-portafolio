# Portafolio de Dereck Enrique Ventura Benitez

Sitio personal de un estudiante de Ingeniería en Desarrollo de Software. Incluye presentación, tecnologías, el proyecto Ramo Recuerdos Floristerías, dos repositorios públicos y enlace al perfil de GitHub.

## Abrir localmente

Abre `index.html` en tu navegador. No requiere instalación ni compilación.

## Archivos

- `index.html`: contenido y navegación.
- `style.css`: diseño adaptable a teléfonos y computadoras.
- `vercel.json`: configuración para publicar como sitio estático.

## Actualizar

1. Edita y guarda los archivos en VS Code.
2. En Control de código fuente, prepara los cambios con **+**.
3. Escribe un mensaje y crea un commit.
4. Pulsa **Sincronizar cambios** para subirlos a GitHub.

Cuando el repositorio esté conectado con Vercel, los cambios de `main` generarán una nueva publicación.

## Publicar en Vercel

Importa este repositorio en Vercel. Selecciona **Other** como tipo de proyecto, deja la carpeta raíz en `./` y no configures un comando de compilación. El sitio utiliza HTML y CSS directamente.

Los datos personales se basan en el perfil público de GitHub. Las ilustraciones de los proyectos son composiciones decorativas, no capturas de sus interfaces. El nombre, correo, teléfono y enlace de Ramo Recuerdos fueron proporcionados por su propietario. No se han añadido experiencia laboral, foto ni LinkedIn sin datos confirmados.
